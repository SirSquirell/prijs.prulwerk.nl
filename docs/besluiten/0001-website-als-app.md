# 0001: website die zich als app installeert (PWA)

Datum: 2026-10-08 · Status: besloten (Mathijs en Claude, vóór de councils)
Vraag: website of native app?
Besluit: PWA op prijs.prulwerk.nl. Op het beginscherm te zetten, met eigen icoon en pushmeldingen.
Waarom: geen App Store, geen Apple-ontwikkelaarsaccount, één codebase, past op GitHub Pages.
Risico: push op iPhone werkt alleen vanaf het beginscherm (iOS 16.4+). Dat leggen we in de app uit.
Terugdraaien kan door: later een native schil eromheen, de API blijft hetzelfde.
