# prijswacht

Privé prijstracker op `prijs.prulwerk.nl`. Volgt producten bij Nederlandse winkels, meldt het als de
prijs zakt, en zegt rond Black Friday of een korting echt is.

Nog in aanbouw. Wil je meebouwen met Claude Code: open deze map en lees `CLAUDE.md`.

- `docs/brief.md`: wat en waarom
- `docs/architectuur.md`: hoe
- `docs/councils.md`: hoe belangrijke keuzes worden gemaakt
- `docs/besluiten/`: wat al besloten is
- `docs/design/`: schermen, tokens, icoon
- `docs/status.md`: waar het nu staat
